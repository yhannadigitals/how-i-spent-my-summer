# How I Spent My Summer: My Little Summer Adventures

A playful React + TypeScript children’s coloring book app with:
- a cheerful summer cover
- gallery and page reader
- digital coloring tools (brush, eraser, fill, undo, clear)
- browser-local save progress
- print-friendly view
- downloadable PDF export

## Quick start

1. Install dependencies:
   npm install
2. Start the dev app:
   npm run dev
3. Open the local URL in your browser.

## Build for production

npm run build

## Notes

This prototype includes a working cover and several original black-and-white SVG coloring pages. The app is designed so you can add additional pages by creating SVG files in `public/art` and registering them in `src/data/pages.ts`.
